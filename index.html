Scaling an EV Platform to 500K+ Daily Transactions

Engineering · Scale · EV Charging SaaS Platform

Context & Challenge

An EV charging SaaS platform needed to scale rapidly without service degradation. Monolithic bottlenecks and synchronous request chains choked under driver charging peaks, degrading API responsiveness.

My Role & Ownership

Senior Software Engineer leading backend distributed engineering. Built horizontally scalable microservices, asynchronous message queues, and low-latency database queries.

Engineering & Technical Decisions

  • Kafka Event Streaming to decouple charging sessions from blocking request chains
  • Redis Sentinel Caching for sub-millisecond session lookup on high-traffic endpoints
  • PostgreSQL Query Optimization with specialized indexing for high-write transactions
  • Kubernetes (EKS) autoscaling policies tuned to real-time traffic surges

Measurable Outcome

Platform reliably supported 500K+ daily transactions at 99.9% uptime. Delivered a 5× API performance gain and 30× capacity expansion from initial limits.

EV Protocol Integration: OCPP 1.6/2.0 & OCPI Roaming

Engineering · IoT Interoperability · EV Charging Platform

Context & Challenge

EV platforms must interface with physical hardware (OCPP) and roaming clearinghouses (OCPI). Vendor deviations from spec frequently caused session dropped messages and billing mismatches.

My Role & Technical Execution

Defined product specifications and co-engineered protocol handling for OCPP 1.6 (with OCPP 2.0 exposure) and roaming integration with partner networks.

Key Decisions & Trade-offs

  • Designed fault-tolerant state machine handling charger edge-case disconnections
  • Built an abstraction layer isolating core billing logic from non-compliant charger firmware
  • Standardized roaming tariff translation to prevent inter-network rounding discrepancies

Measurable Outcome

Shortened charging station onboarding timelines, significantly reduced communication drop-offs, and enabled seamless driver roaming across partner charging networks.
